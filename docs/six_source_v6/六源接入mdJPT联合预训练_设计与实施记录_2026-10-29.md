## 0. 一句话结论

四源语料加入两个新的静息态焦虑数据集（ds007609：STAI 状态+特质，51 人；ds004902：睡眠剥夺 SAI，有效 35 人），六源联合预训练预算仍是 **36 窗/步 ≈ 6.6 GiB**（实测峰值 6583 MiB < 6700 上限），ISA 白名单扩到五源（EEGMAT 维持仅 CDA），终点任务首次可用：STAI trait/state 与 SAI/ΔSAI 的 LOSO 回归读出 + 线性谱基线对照。

## 1. 新数据集与清洗管线（新建，旧 v4 清洗脚本已随 E 盘丢失）

`tools/build_clean_v6.py`：BIDS → `processed_clean_v6/{SRC}/{sub}/`（v4 中间契约：`signals.npy` 60ch µV @125Hz float32 + `windows.jsonl` + `summary.json`）。两源都是 EEGLAB `.set`+`.fdt`（MNE 的 EEGLAB 读取器对两者都崩，改为 scipy 直读 MATLAB 头 + channel-major float32）。

| | DS007609 | DS004902 |
|---|---|---|
| 原始 | 256 导 EGI HCGSN，500Hz，**作者已预处理**（0.1-50Hz + CleanLine + ICA + 坏道球面插值回补，平均参考） | 61 导 10-20 扩展，500Hz，**原始未清洗**，FCz 在线参考 |
| 通道映射 | 256→60 一次性球面样条（Perrin，MNE `_make_interpolation_matrix`，恒定场校验 \|行和−1\|=0.0000）；电极坐标取自逐被试 `electrodes.tsv`（51 人哈希一致） | 61→60：57 通道恒等 + 3 通道（FCz/PO5/PO6）样条插值；丢 AF7/AF8/TP9/TP10 |
| 额外清洗 | 无（已预处理） | 0.1-45Hz Butterworth 零相位（sosfiltfilt） |
| 重采样 | polyphase 500→125Hz | 同左 |
| 结构 | EO-EC-EO-EC 四块（59/59/59/63s，跨被试取最小块长保证均匀）→ 114 窗/人 | NS/SD × EO/EC 四段（各 300s）→ 592 窗/人 |
| 被试 | 51/51 | **35/71**：闭眼只采了 38 人 + 3 人 fdt 源头截断（如 sub-01 ses-2 eyesopen 27.8MB ≠ 36.6MB），按"4 段齐全+字节数校验"剔除 |
| Session 顺序 | 无歧义 | **被试间平衡（NS→SD / SD→NS）**：`SessionOrder` 归一化后再排规范序，否则 ISA 会把 A 的剥夺态对 B 的正常态当正样本 |
| QC | 幅值旗标（>150µV）只登记不剔除（v4 政策）；旗标率 15.3% | 同左；旗标率 29.1%（原始数据正常水平） |

## 2. 切片适配与预算

`tools/build_sliced_v6.py`（复用 build_sliced_v4 的 `robust_z`/`load_windows`/io 布局）：

- **DS007609 / DS004902：K=2 分组**（EO 池、EC 池；窗索引 = 条件+session+偏移，跨被试严格对齐），n_vids=2 → 各 4 窗/步。ISA 档 weak（协议锁定的均匀布局）。
- **DEAP-v6 重建（K=4×10 视频）**：最初想直接 n_vids 8→4，但 K=8 时 `n_samples_per_trial=int(4/8)=0` 会让每个 batch 退化成"只从最后一组视频采样"。重建到 `mdjpt_data_v6/DEAP`（K=4，280 窗/组），窗口与 v4 完全相同（cov_frobenius 17.06 一致可证），仅分组变化；4src 已发表构建不受影响。n_vids=4 → 每组恰 1 窗，无退化。
- **EEGMAT n_vids 3→2**（CDA-only，减少 2 窗换显存）。
- 最终预算：DASPS 8 + DEAP 8 + SAM40 8 + EEGMAT 4 + DS007609 4 + DS004902 4 = **36 窗/步**，实测峰值 **6583 MiB**（38 窗时 6943 MiB 超上限；torch 2.12 的工作区比 4src 时期大）。

**门禁（`mdjpt_data_v4/build_audit_v6.json`）**：GATE1 逐通道 std ∈ [0.65,1.87] ⊂ [0.3,3] PASS；GATE2 六源 CDA Frobenius 比 max/min = 2.988 < 3 PASS（新源为静息数据，协方差_offdiag 系统性偏低：DS007609 10.51 / DS004902 8.71 vs 旧源 17-26）。

## 4. 终点任务（本项目首次有数据）

| 源 | 目标 | 类型 | 覆盖 |
|---|---|---|---|
| DS007609 | stai_state, stai_trait | 回归 | 51/51 人（实测 trait 范围 32-69） |
| DS004902 | SAI_NS, SAI_SD, SAI_delta | 回归 | **实际无数据**：SAI 只采在 sub-39~69（恰为无闭眼 EEG 的被试），与 35 个有效 EEG 被试零交集；探针将如实报"样本不足" |
| 旧四源 | SAM/效价唤醒/压力/条件 | 回归+分类 | 同 4src |

**ds004902 的定位修正**：它对六源的贡献是预训练语料多样性（EO/EC × NS/SD 的静息态变体），不是焦虑标签。SAI 易感性问题（"睁眼 EEG 预测谁在剥夺后焦虑升幅大"，31 人 × 2 session × EO）需要给 sub-39~69 单独切窗、用各 checkpoint 提特征后做 LOSO——留作后续附加子研究，不阻塞本次矩阵。

读出：LOSO 岭回归（α=10，折内标准化），对照 = 常数均值 + 线性谱基线（5 频带×60 对数功率）。ISA/CDA/ISA+CDA × 3 种子完整矩阵，与 4src 协议同构。

## 5. 边界与不许做的事（承接 v4 §7）

- ds004902 的 SD session 是睡眠剥夺操纵后的状态，六源预训练中它只是"一种静息态变体"；**不得**把 SD 相关的读出解释成临床焦虑。
- ds007609/ds004902 的 ISA 档是 weak（条件锁定而非刺激锁定）：正样本语义 = "同条件+同偏移"，弱于 DEAP 的 exact。若日后要收紧，需在报告里单列。
- 新源旗标率（15%/29%）高于旧源均值，窗级剔除会破坏均匀布局，维持 v4 的"登记不剔除"政策。
- LEMON（nm000179）未纳入（用户决定不下载）；如日后纳入需重新过 CDA 平衡门。
